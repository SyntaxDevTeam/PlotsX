# PlotsX

Twój teren, twoja ekipa, twoje zasady. PlotsX pozwala tworzyć chronione działki w Minecraft, zapraszać znajomych i zabezpieczać prywatne skrzynie. Najważniejsze opcje znajdziesz w wygodnym menu.
